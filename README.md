# BoboScoop

Интернет-магазин сюрприз-боксов в тематике Sanrio и Chiikawa: лендинг с конструктором бокса, корзина, онлайн-оплата через ЮKassa, уведомления в Telegram и админка.

Стек: Next.js 15 (App Router), Tailwind CSS 4, Postgres + Drizzle ORM.

## Что есть

- **Главная**: Боботик, как это работает, конструктор бокса (1–3 ложки, видео, пожелания, до 5 предметов «не класть»), превью готовых боксов, отзывы, блок про Боботика, доставка, FAQ.
- **Каталог** (`/shop`): бокс на ложки и готовые боксы с фиксированной ценой, фото и остатком. У каждого готового бокса своя страница.
- **Что в боксе** (`/assortment`): из чего собираются боксы на ложки.
- **Отзывы** (`/reviews`): текстовые отзывы и скриншоты сообщений; скриншот открывается на весь экран.
- **Корзина**: до 5 боксов на ложки (у каждого свои пожелания) плюс готовые боксы. Доставка: служба (Яндекс Маркет / Ozon / Wildberries) и необязательная надбавка за регион, всё оплачивается сразу.
- **Оплата**: ЮKassa. Пока ключей нет, работает демо-оплата, которая всегда проходит.
- **Админка** (`/admin`): заказы со статусами, готовые боксы (цена, фото, остаток, лимит на заказ), массовая загрузка скриншотов отзывов, ассортимент с фото и наличием, цены (ложки, видео, лимит боксов), персонажи и цвета, тексты сайта, доставка, отзывы, FAQ, оферта и политика.
- **Telegram**: бот присылает каждый оплаченный заказ со всеми пожеланиями.

Все лимиты и цены проверяются на сервере, подменить их из браузера нельзя.

## Запуск на Vercel

1. Импортируйте репозиторий в Vercel.
2. **Storage → Create → Neon (Postgres)**: `DATABASE_URL` появится сам.
3. **Storage → Create → Blob**: нужен для загрузки фото из админки, `BLOB_READ_WRITE_TOKEN` появится сам.
4. **Settings → Environment Variables**, добавьте:
   - `NEXT_PUBLIC_SITE_URL`: адрес сайта, например `https://boboscoop.vercel.app`
   - `ADMIN_PASSWORD`: пароль от админки
   - `ADMIN_SECRET`: случайная строка от 32 символов
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`: см. ниже
   - `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`: см. ниже
5. Redeploy. При сборке таблицы создаются сами и заполняются стартовым ассортиментом, службами доставки и FAQ.

## ЮKassa

- **Без ключей** включена демо-оплата: на странице заказа кнопка «Оплатить (демо)».
- **Тестовый магазин ЮKassa**: в личном кабинете ЮKassa создайте тестовый магазин и возьмите его `shopId` и секретный ключ `test_...`. Оплата проходит тестовой картой `5555 5555 5555 4477`, срок любой будущий, CVC любой.
- **Боевой режим**: замените ключи на боевые и сделайте Redeploy.
- В настройках магазина ЮKassa укажите HTTP-уведомления на `https://ВАШ-САЙТ/api/yookassa/webhook` (событие `payment.succeeded`). Даже без этого статус проверяется, когда покупатель возвращается на сайт.
- Чеки 54-ФЗ: если в ЮKassa включены чеки (например, «Чеки от ЮKassa» для самозанятых), поставьте `YOOKASSA_SEND_RECEIPT=true`.

## Telegram-уведомления

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен в `TELEGRAM_BOT_TOKEN`.
2. Напишите боту любое сообщение, затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}`. Это `TELEGRAM_CHAT_ID`. Для группы добавьте бота в группу, тогда id будет отрицательным.

## Перед запуском с реальными деньгами

В админке → «Цены и тексты» заполните **продавца (ФИО, ИНН)**, **оферту** и **политику конфиденциальности**: сейчас там заглушки. Также проверьте цены доставки (стоят по 250 ₽ для примера) и тексты про Боботика.

## Локальная разработка

```bash
cp .env.example .env   # укажите DATABASE_URL на свой Postgres
npm install
npm run db:migrate     # таблицы + стартовые данные
npm run dev
```

После изменения `src/lib/db/schema.ts` запустите `npm run db:generate` и закоммитьте новую миграцию из `drizzle/`.
